# Solace Garden music

Put the garden's recordings in this folder (MP3, OGG or WAV) and rebuild the garden
(**New World ▸ Build Solace Garden**). It plays them in this order, then any others,
streamed and looping the playlist:

| Order | Piece | Name the file with |
|---|---|---|
| 1 | Chopin, Nocturne in E-flat major, Op. 9 No. 2 | `Op9 No2` |
| 2 | Chopin, Nocturne in D-flat major, Op. 27 No. 2 | `Op27 No2` |
| 3 | Chopin, Nocturne in C minor, Op. 48 No. 1 | `Op48 No1` |
| 4 | Chopin, Nocturne in B-flat minor, Op. 9 No. 1 | `Op9 No1` |
| 5 | Chopin, Nocturne in C-sharp minor, Op. posth. (No. 20) | `C sharp minor` |
| 6 | Rachmaninoff, Piano Concerto No. 2 in C minor, Op. 18 | `Concerto 2` |
| 7 | Rachmaninoff, Piano Concerto No. 3 in D minor, Op. 30 | `Concerto 3` |

For example `Chopin - Nocturne Op9 No2.mp3` or `Rachmaninoff - Concerto 2 - I. Moderato.mp3`
(a concerto's three movements as separate files sort in order by name).

## Rights

The compositions are in the public domain, but each **recording** has its own copyright.
Use recordings you are allowed to ship in the app:

- **Public-domain recordings**: Musopen (musopen.org) has released public-domain recordings
  of Chopin's nocturnes; check each file's licence there.
- **Creative Commons recordings**: Wikimedia Commons and the Internet Archive host some
  performances under CC BY / CC BY-SA. These need the performer credited in the app.
- **Licensed recordings**: for the Rachmaninoff concertos, most good recordings are
  commercial. License one, or commission one.

While this folder has no recordings, the garden plays Solace's music.

## Credits

When a recording's licence asks for a credit (CC BY, CC BY-SA), add a line for it to `CREDITS.txt` in this
folder: the file name without its extension, a bar, then the credit, e.g.

    Chopin - Nocturne Op9 No2 | Performed by <performer> · Musopen · CC BY 4.0

The garden's music menu shows it small under the track name while that track plays. Rebuilding the garden warns
about any recording here with no line in `CREDITS.txt`.
