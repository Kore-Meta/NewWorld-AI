# Music history station pictures: sources and licences

Pictures shown in the history station's frame in Solace (see `Tools/History/content-c.js` for the steps they belong to). Every file is **public domain**. Each was checked on its Wikimedia Commons file page, which shows "Public domain" and "Copyrighted: False". They were downloaded from Commons via Special:FilePath at 1024 px or less on the long side, as JPG. Unity imports them at 1024 px at most, with ASTC 6x6 on Quest (SolaceComposerPicture). No attribution is legally required. The station's Sources panel credits Wikimedia Commons and the holding institutions as a courtesy.
